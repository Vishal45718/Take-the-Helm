# Grand Line Dashboard — Agent Instructions
- Inspect before modifying.
- Make one focused change per task.
- Preserve working behavior unless explicitly changing it.
- Prefer plain HTML/CSS/JS unless the existing project requires otherwise.
- Never use alert() for application UI.
- Avoid brittle nth-child styling; use semantic classes/data attributes.
- Keep configuration separate from rendering.
- Centralize persistent state.
- Never silently delete user data.
- Keep the project runnable after every task.
- Do not implement SaaS, accounts, payments, cloud sync, or extension packaging unless explicitly requested.
After each task report: files changed, changes, verification, remaining issues, and next task.
