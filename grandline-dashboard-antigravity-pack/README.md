# Grand Line Dashboard — Antigravity Workflow
This is a personal local-first Firefox new-tab dashboard. Monetization/SaaS is deferred.

Workflow:
1. Read AGENTS.md and PHASE_STATUS.md.
2. Paste exactly one prompt from PROMPTS.md into Antigravity.
3. Review changes.
4. Run/verify the dashboard.
5. Update status.
6. Move to the next prompt only after verification.

Files:
- MASTER_PLAN.md
- TASK_CHECKLIST.md
- BUG_TRACKER.md
- PHASE_STATUS.md
- PROMPTS.md
- ARCHITECTURE.md
- AGENTS.md
