# Grand Line Dashboard — Master Plan
Goal: evolve the current personal Firefox new-tab dashboard into a polished, maintainable, customizable local-first dashboard.

## Phases
0. Baseline and safety
1. Extract CSS/JS and clean structure
2. Config-driven links/categories
3. State layer, modal/toast, real settings
4. Wallpaper and theme customization
5. Search providers
6. Widget architecture and productivity widgets
7. Drag/drop, shortcuts, command palette, responsive/accessibility
8. Versioned state, migrations, export/import
9. Final quality audit and documentation

## Deferred
User accounts, backend, cloud sync, payments, SaaS hosting, Chrome extension, marketplace, monetization.
